Siteplan

Site Name

Nova's Novels—this name uses alliteration to make a snappy title for a website that one can use to read Nova's novels.

Site Purpose

This site provides public access to completed and w.i.p. novels written by Nova.

Scenarios

  • Can I get a physical copy of a novel?
  • Can I make an adaptation of one of these novels?
